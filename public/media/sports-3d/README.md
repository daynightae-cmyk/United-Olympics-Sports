# Sports 3D local media

This directory is reserved for production-localized UOS sports 3D identity assets.

No binary asset is committed until its source layer is an exact sport/identity match and the intended-use license is reviewed. Runtime components therefore fail closed instead of substituting a similar sport.

See `src/design/sports3d/SOURCE.md` and `src/design/sports3d/sports3d.registry.ts`.
